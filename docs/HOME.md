# 🎬 Welcome to CineStack!

Thank you for visiting! CineStack is a full-stack movie platform built with **Next.js 15**, **TypeScript**, **Supabase**, and **Tailwind CSS**.

## 👋 Untuk Pengunjung

CineStack adalah portfolio project yang menunjukkan kemampuan **full-stack engineering**. Kamu bisa:
- 🎥 **Browse** ribuan film dari TMDB
- ⭐ **Review & rate** film favorit
- 📋 **Buat watchlist** personal
- 🗞️ **Baca berita** film terbaru

## 💼 Untuk Klien / Recruiter

Lihat langsung kualitas kode dan arsitektur:
- TypeScript **strict mode** — zero `any` types
- **Server Components** + **ISR** untuk performa
- **Row Level Security** di PostgreSQL
- **CI/CD** dengan GitHub Actions
- **Vitest** — 16+ test passing
